# 화면 구조 조사와 결정 (2026-10-31)

## 조사에서 얻은 것
| 사례 | 구조 | 가져온 점 |
|---|---|---|
| 스타듀밸리 | 메뉴 하나에 탭: 소지품, 기술, 관계, 지도, 제작, 수집품, 설정 | 가진 것(소지품)과 쌓은 기록(수집품)을 나눈다 |
| 동물의 숲 | NookPhone 하나로 기능을 모으고, 마일(달성 보상)은 별도 앱 | 정원 화면에는 조작을 적게 둔다 |
| Finch | 아래 탭: 홈, 퀘스트, 상점, 친구, 가방 | 가방·상점·할 일을 분리한다. 리뷰에서 할 일 버튼이 메뉴 뒤로 밀린 점이 비판받았다 |
| 드림라이트 밸리 | 가구 메뉴는 카테고리별. 소지품이 많으면 불편하다는 평이 많다 | 종류별 탭을 처음부터 둔다 |
| 출석 화면 일반 | 강제 팝업보다 버튼과 표시로 여는 방식이 있다. 다만 놓친 날 표시, 연속 초기화 사례도 많다 | 버튼으로 열고, 놓친 날은 표시하지 않는다 |
| 모바일 조작 영역 | 자주 쓰는 것은 아래쪽, 드문 것은 위쪽 | 메뉴를 아래로 옮기고 설정은 위에 둔다 |

자료 수준: 위키와 리뷰, 블로그 위주이고 실제 게임 화면을 직접 확인하지는 않았다. 팔리아, 포켓몬 슬립, 원신의 출석 화면은 자료를 찾지 못해 넣지 않았다.

## 분류 기준
메뉴는 "무엇을 하러 왔나"로 나눈다.

| 메뉴 | 뜻 | 내용 |
|---|---|---|
| 활동 카드 | 오늘 할 일 | 항상 화면에 둔다. 메뉴 안에 넣지 않는다 |
| 가방 | 내가 가진 것 | 씨앗 / 소품 / 식물 |
| 수첩 | 내가 쌓아 온 것 | 기록 / 도감 / 출석 |
| 꾸미기 | 정원을 바꾸는 모드 | 창고도 소품 / 식물로 나눈다 |
| 상점 | 살 것 | 모루의 작업대 |
| 설정 | 드물게 쓰는 것 | 오른쪽 위 |

출석을 수첩에 둔 이유: 도장판은 물건이 아니라 찾아온 횟수의 기록이다.

## 화면 배치
- 아래쪽: 조이스틱, 가방·수첩·꾸미기·상점, 대화, 활동 카드
- 위쪽: 정원 이름, 시야 조절, 설정
- 왼쪽: 열매 수. 봉투와 선물은 있을 때만 보인다
- 알림은 빨간 배지를 쓰지 않는다(원칙). 탭의 숫자도 가진 개수만 뜻한다

## 후속 후보
- 소품이 늘면 가방 안에 소품 종류 필터
- 처음에는 메뉴를 적게 보여 주고 차차 늘리는 방식(동물의 숲). 잠금처럼 보이면 안 되어서 시연 뒤 판단
