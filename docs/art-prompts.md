# ChatGPT 이미지 프롬프트 (임시 그림용)

팀원 그림이 오면 교체한다. 받은 이미지는 `art/source/`에 넣고 `tools/slice_art.py`로 자른다.

## 쓰는 법
- 새 대화에서 **기준 이미지**를 먼저 첨부한다.
  - 공통: `art/guide/theme_a_props.png`, `art/guide/theme_a_decorated.png`
  - 인물: `art/source/sprout2-basic.webp`도 함께
- 아래 **공통 지시문**을 붙이고, 그 밑에 만들 항목의 지시문을 붙인다.
- 한 번에 한 장씩 만든다. 시트 안의 칸이 서로 겹치면 다시 만든다.

## 공통 지시문
```text
첨부한 기준 이미지와 같은 그림체로 그려줘.
따뜻하고 차분한 2D 픽셀 페인팅, 굵은 짙은 갈색 윤곽선, 위에서 내려다보는 3/4 게임 시점,
부드러운 낮빛, 위·왼쪽이 밝고 아래·오른쪽에 짧은 접촉 그림자.
배경은 완전히 투명하게(투명이 안 되면 단색 흰색). 글자, 워터마크, 칸 번호, 테두리를 넣지 마.
여러 개를 그릴 때는 같은 크기의 격자에 맞추고 칸마다 넉넉한 여백을 둬서 서로 겹치지 않게 해줘.
```

## 1. 느리 (달팽이) — 1순위
```text
작은 정원에 사는 달팽이 캐릭터 "느리". 자연을 관찰하고 짧은 농담을 좋아하는 차분한 주민.
둥글고 큼직한 꿀빛 갈색 나선 껍데기, 크림색 몸, 작은 더듬이 두 개, 작은 눈과 살짝 웃는 입.
옆모습이 기본이고 머리가 몸에 비해 큰 귀여운 비율. 옷과 소품은 없음.
가로 4칸 시트: 앞모습, 옆모습 서기, 옆모습 걷기, 뒷모습. 네 칸 모두 크기와 색이 같게.
```

## 2. 모루 (두더지) — 1순위
```text
작은 정원에 사는 두더지 캐릭터 "모루". 표지판을 만드는 꼼꼼한 장인이고 말이 간결한 주민.
둥글고 짧은 몸, 짙은 회갈색 털, 분홍색 코, 작은 눈, 크고 둥근 앞발, 크림색 작업 앞치마.
앞치마 주머니에 연필 하나. 머리가 큰 귀여운 비율.
가로 4칸 시트: 앞모습, 옆모습 서기, 옆모습 걷기, 뒷모습. 네 칸 모두 크기와 색이 같게.
```

## 3. 피오 (참새) — 1순위
```text
작은 정원에 사는 참새 캐릭터 "피오". 정원의 소리를 모으는 호기심 많고 가벼운 주민.
둥근 몸, 갈색 머리와 날개, 크림색 배, 짧은 부리, 초롱한 작은 눈, 목에 작은 수첩 끈.
머리가 큰 귀여운 비율.
가로 4칸 시트: 앞모습, 옆모습 서기, 옆모습 깡총 뛰기, 뒷모습. 네 칸 모두 크기와 색이 같게.
```

## 4. 아이콘 묶음 — 1순위
```text
게임 UI 아이콘 6개를 가로 3칸, 세로 2칸 격자로 그려줘. 작게 줄여도 알아볼 수 있게 형태를 단순하게.
1) 정원열매: 둥글고 작은 산딸기 색 열매에 잎 하나
2) 씨앗: 흙색 작은 씨앗 하나가 놓인 모습
3) 새싹: 흙 위에 잎 두 장이 난 작은 새싹
4) 꽃봉오리: 초록 줄기에 닫힌 꽃봉오리
5) 방문 선물함: 나무 상자에 끈이 묶인 작은 선물함
6) 상점 표지: 망치와 나무 표지판
```

## 5. 쉬는 모습 새싹이 — 2순위
`art/source/sprout2-basic.webp`를 꼭 첨부한다.
```text
첨부한 새싹 캐릭터와 똑같은 캐릭터가 쉬는 모습을 그려줘.
굵은 갈색 윤곽, 머리 크기, 잎 두 장, 얼굴 비율, 색을 그대로 유지해.
풀밭에 편하게 앉아 눈을 감고 살짝 웃는 모습. 잠든 표시(Zzz)는 넣지 마. 캐릭터 1개만.
```

## 6. 모루의 작업대 — 2순위
```text
정원 집 옆에 놓인 작은 나무 작업대. 위에 망치, 작은 표지판, 연필, 나무 조각이 정돈되어 있다.
꿀빛 나무, 둥근 모서리, 소박한 느낌. 사람이나 동물은 넣지 마. 물건 1개만.
```

## 7. 열매나무 — 3순위 (다음 기능용)
```text
낮은 열매나무 한 종류의 성장 단계를 가로 4칸 시트로 그려줘.
1) 묘목, 2) 어린 나무, 3) 다 자란 나무(열매 없음), 4) 다 자란 나무(붉은 열매가 달림).
둥근 잎 덩어리, 굵은 줄기, 뿌리가 땅에 닿는 위치를 네 칸 모두 같게. 그림자는 짧게.
```

## 8. 상점 소품 추가 — 3순위
```text
정원 꾸미기 소품 6개를 가로 3칸, 세로 2칸 격자로 그려줘.
나무 표지판, 낮은 나무 울타리 한 칸, 작은 정원 등불, 돌 징검다리, 나무 물뿌리개, 작은 나무 상자.
크기 비율은 기준 이미지의 소품과 비슷하게. 강·온실·다리 같은 큰 구조물은 넣지 마.
```

## 받은 뒤 확인할 것
- 윤곽 굵기가 새싹이와 비슷한지
- 잎·눈 같은 특징이 칸마다 같은지
- 아이콘을 44px로 줄여도 알아볼 수 있는지
