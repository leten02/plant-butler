# 월요일 데모 범위와 결정 사항 (2026-10-31 확정)

기준 문서: 스토리 바이블 v5.0, 오늘 한걸음 보상·성장 기능 명세서, 이 프로젝트의 `docs/spec.md`.
두 팀 문서가 서로 달랐던 부분(랜덤 씨앗, 출석 보상, 열매·상점)을 아래처럼 정했다.

## 1. 정한 것
| 항목 | 결정 |
|---|---|
| 완료 보상 | **씨앗 주머니만.** 소품을 바로 주는 방식은 없앤다. 하루 1개(완료한 날, 쉬기를 고른 날 모두), 하루 활동 3개 상한은 그대로 |
| 씨앗 종류 | **랜덤.** 일반 꽃 8종(합 55%), 열매나무 2종(합 30%), 특별 꽃 4종(합 15%). 중복 가능. 꽝·재뽑기·확률 표시 없음 |
| 씨앗함 | 봉투 도착 때 `씨앗 열어보기 / 씨앗함에 보관`, 열면 `심기 / 나중에 심기 / 도감 보기`를 고른다. 느리와의 대화 끝에서도 씨앗함으로 간다. 씨앗함의 씨앗도 도감에 만난 식물로 센다. 안 심은 씨앗과 안 연 봉투는 씨앗함에 사라지지 않고 남는다. 심기를 누르면 텃밭으로 다가가 빈 두둑을 밝게 보여 주고, 사용자가 누른 곳에 심긴다. 고르지 않고 나가면 씨앗은 씨앗함에 남는다. 밭이 차도 봉투는 열 수 있다 |
| 성장 | 심은 날 **씨앗** → 다음 날부터 **새싹** → +3일부터 **꽃**. 심은 날과 오늘로 계산하며 저장 상태 없음. 물 주기·시듦 없음, 남은 일수 표시 없음 |
| 심는 곳 | 정원의 나무 틀 텃밭(밭 그림 한 장)의 두둑 16곳. 키우는 식물은 거기에만 놓고 옮길 수 있고, 소품과 수확한 꽃은 마당 어디든. 텃밭 자체도 꾸미기에서 끌어 옮길 수 있다(소품·새싹이·주민 위, 숲 밖은 불가) |
| 수확 | 꽃이 핀 식물을 눌러 **정원열매 3개**를 받는다. 꽃은 **창고로 가고 두둑이 빈다**(16일이면 밭이 차는 문제 해결). 도감에는 남는다. 안 따면 꽃은 밭에 그대로 있다. 재수확은 없다(나무만) |
| 열매나무 | **마당 칸**에 심고 씨앗 → 묘목(+1일) → 어린 나무(+3일) → 다 자람(+6일). 첫 열매 3개, 수확해도 나무는 남고, 그 뒤 **주머니를 받은 날이 3번** 쌓이면 다시 열려 1개를 받는다(쉬기 포함, 연속 불필요, 날짜만으로는 안 열림). 줄기는 걸어서 지나갈 수 없다. 숫자는 임시값 |
| 수확한 꽃 | 창고에서 꺼내 **마당에 장식으로** 놓는다. 열매는 다시 열리지 않는다. 수확 전에 창고에 넣은 식물은 밭으로 돌아간다 |
| 상점 | **모루의 작업대**에서 열매로 소품 6종 구매. 샀으면 꾸미기 창고에 들어가고 직접 놓는다 |
| 가격 | 벤치 4 · 찻상 5 · 꽃 화분 6 · 화분 선반 7 · 새 물그릇 8 · 해먹 10 (임시, 시연으로 조정) |
| 메뉴 구조 | 가방(씨앗·소품·식물) = 가진 것, 수첩(기록·도감·출석) = 쌓아 온 것. 아래쪽에 가방·수첩·꾸미기·상점, 위에 설정. 근거는 `docs/ux-research.md` |
| 방문 선물함 | 접속한 날 **열매 2개**. **도장판**(7칸 두 줄)에 방문 횟수만큼 도장이 쌓이고 3·7·14번째 칸에 기념 선물 그림이 보인다. 날짜 달력이 아니라서 쉰 날이 빈칸으로 남지 않는다. 누적 3회 소품, 7회 특별 씨앗 주머니, 14회 소품. **연속 기록·초기화 없음**, 쉬어도 누적은 그대로 |
| NPC | 느리(달팽이)·모루(두더지)·피오(참새)가 자기 자리 근처를 천천히 서성인다. 가까이 가거나 누르면 멈추고 대화. 모루 상점은 화면 버튼으로도 연다 |
| 대사 | 스토리 문서의 대사를 그대로 쓴다. 페르소나 주입은 다음 회의에서 |
| 그림 | UI·NPC 그림은 다른 분이 맡는다. 오기 전까지 지금 그림과 임시 표시로 가고, 오면 교체 |

| 첫 방문 | 프롤로그 P01~P03을 `core/data/story.json`으로 재생한다. 언제든 닫을 수 있고, 어느 선택이든 첫 씨앗 주머니 1개를 받는다. 그날 활동 주머니와 별개. 조약돌 소품은 그림이 없어 뺐다 |
| 효과음 | 파일 없이 합성음(`ui/sound.ts`). 작고 부드럽게, 설정의 소리 끄기를 따른다 |
| 나무 간격 | 다른 나무와 세 칸 이상 떨어뜨려 심는다 |
| 마당 꽃 | 작아서 지나갈 수 있다. 앞뒤 순서만 맞춰 그린다 |

## 2. 원칙 (어기지 않는다)
- 보상은 현실 활동 완료에서만. 접속만으로는 열매 2개 정도의 작은 선물뿐이다.
- 빠진 날에 줄거나 사라지는 것이 없다. 연속 일수·남은 일수·빠진 일수를 보여 주지 않는다.
- 희귀(특별) 씨앗은 외형의 차이일 뿐 열매 수확량은 같다.
- 메인 이야기는 활동·씨앗·열매·상점과 관계없이 볼 수 있어야 한다(이번 데모에는 이야기 본편은 없음).
- NPC 대사에 평가·압박·감정 추측이 없다("오늘 안 오면 손해" 같은 말 금지).

## 3. 이번 데모에 넣지 않는 것 (후속)
서브 스토리 6편, 지도판 이야기 본편(A~E, 재생 틀과 선택 기억은 있고 대사를 json에 넣으면 된다), 도움받기 화면 연결, NPC 페르소나·챗봇형 대화.

## 4. 필요한 그림 (팀 그림이 오면 교체)
ChatGPT로 만든 임시 그림을 넣었고, 프롬프트는 `docs/art-prompts.md`에 있다.
- 넣은 것: NPC 3종(앞·옆·걷기·뒤), 정원열매·씨앗·새싹·꽃봉오리·선물함·상점 아이콘
- 아직 없는 것: 쉬는 모습 새싹이, 모루 작업대, 열매나무(코드로 만든 임시 그림), 상점 소품 추가

## 5. 일정
- 토: 규칙(씨앗·성장·수확·열매·상점·선물함)과 테스트, 화면 연결
- 일: 그림 교체, 캐릭터 통일, 샘플 데이터, 아티팩트 재배포
- 월 오전: 발표 순서대로 리허설
