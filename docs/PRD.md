# 오늘 한걸음 PRD (1차 버전)

서비스 배경·근거·대상자는 [서비스 기획서](https://claude.ai/artifact/NzWckAZavug2FuwvZcMN9p)에 있음. 이 문서는 개발에 필요한 정의와 완료 조건만 담음. 팀 운영(역할·일정·규칙)은 `docs/notion-plan.md`.

## 1. 목표

- 상담·치료를 마친 지 6개월 이내 성인을 위한 게임형 일상 회복 앱의 4주 시범 운영용 첫 버전.
- 바꾸려는 행동 하나: **놓친 다음 날 다시 시작하기**. 모든 기능은 이 행동을 쉽게 만드는지로 판단함.

## 2. 범위

**1차에 넣음:** 미션 제안·바꾸기·난이도 낮추기, 완료·오늘은 쉬기, 정원과 꽃, 복귀 메시지, 2단계(시간·장소), 3단계(활동·성공 기준), 알림 시간 설정, 긴급 연결, 한 줄 회고, 기록 보기, 이벤트 로그.

**넣지 않음:** 연속 기록(스트릭), 빨간 미완료 배지, 시드는 식물 같은 벌칙 연출, 기분 점수, AI나 앱이 마음 상태를 판단하는 기능, 진단·상담·치료 문구, 순위 비교, 이름·연락처·이메일·진단명 수집.

**뒤로 미룸:** 실제 화분 사진, 사진 AI 피드백, 익명 응원, 이웃 방문, 식물 나눔, 하드웨어.

## 3. 용어와 정의

| 용어 | 정의 |
|---|---|
| 하루 | 한국 시간(Asia/Seoul) 기준 날짜 |
| 기록 | `activity_completed` 또는 `rested` 이벤트. 앱 열기는 기록이 아님 |
| 복귀 | 마지막 기록 날짜와 오늘 날짜의 차이가 2일 이상인 상태에서 앱을 처음 연 것. 하루에 한 번만 발생 |
| 단계 | 1단계 미션(제안 고르고 줄이기), 2단계 일상 연결(시간·장소 직접), 3단계 하루 설계(활동·성공 기준 직접). 언제든 오갈 수 있음 |
| 난이도 | 미션마다 `large`·`medium`·`small` 3가지 문구 |
| 참여 코드 | 시범 참여자에게 앱 밖에서 나눠 주는 코드(예: `P07`). 개인을 알아볼 수 없는 값 |

재설치하면 익명 계정이 새로 생기고 앱 안의 기록은 이어지지 않음. 같은 참여 코드를 다시 입력하면 지표는 참여 코드 기준으로 합쳐서 집계함.

## 4. 이벤트 사전

모든 지표는 `events` 테이블에서 계산함. 이벤트 이름과 필드는 여기서만 정의하고, 코드에서는 이 목록의 타입을 그대로 씀.

| 이벤트 | 언제 | 추가 필드 (`props`) |
|---|---|---|
| `app_opened` | 앱이 포그라운드로 올 때 | - |
| `mission_viewed` | 오늘의 미션이 화면에 보일 때 | `mission_id` |
| `mission_swapped` | 다른 미션으로 바꿀 때 | `from_mission_id`, `to_mission_id` |
| `level_lowered` | 난이도를 낮출 때 | `mission_id`, `from_level`, `to_level` |
| `activity_completed` | 완료를 누를 때 | `activity_id`, `mission_id`(직접 쓴 활동이면 null), `level`, `stage` |
| `rested` | 오늘은 쉬기를 누를 때 | `activity_id`, `stage` |
| `returned` | 복귀 조건을 만족해 앱을 열 때 | `gap_days` |
| `stage_changed` | 단계를 바꿀 때 | `from_stage`, `to_stage` |
| `plan_created` | 2·3단계 계획을 저장할 때 | `plan_id`, `stage` |
| `reflection_added` | 한 줄 회고를 저장할 때 | `activity_id` (메모 내용은 넣지 않음) |
| `emergency_opened` | 긴급 연결 화면이 열릴 때 | `from_screen` |
| `emergency_called` | 전화 버튼을 누를 때 | `target` (`109`, `1577-0199`, `partner`) |

## 5. 데이터

| 테이블 | 주요 컬럼 | 비고 |
|---|---|---|
| `profiles` | `id`(auth.uid), `participant_code`, `partner_code`, `stage`, `notify_time`, `notify_enabled`, `created_at` | 이름·연락처 없음 |
| `missions` | `id`, `category`, `text_large`, `text_medium`, `text_small`, `reviewed` | 팀 작성, `reviewed = true`만 노출 |
| `activities` | `id`, `user_id`, `mission_id`, `custom_text`, `level`, `status`(`completed`·`rested`), `local_date`, `memo` | 꽃 1개 = `completed` 1건 |
| `plans` | `id`, `user_id`, `stage`, `local_date`, `time_text`, `place_text`, `activity_text`, `success_text` | 2·3단계 계획 |
| `events` | `id`, `user_id`, `name`, `props`(jsonb), `occurred_at`, `local_date` | 지표 계산용, 앱에서는 쓰기만 함 |

- RLS: 모든 테이블은 본인 행만 읽고 씀. `missions`는 로그인한 사용자 누구나 읽기만 가능.
- 지표 집계는 `participant_code` 기준 뷰로 만들고, `memo` 컬럼은 집계 뷰에 넣지 않음.
- 미션 시드: 개발용 10개는 C가 넣고, 시범용 30~50개는 D가 검수 후 교체.

## 6. 지표

| 지표 | 계산 |
|---|---|
| 현실 활동 수행 횟수 | 참여 코드별 주간(KST 월~일) `activity_completed` 건수 |
| 중단 후 재참여 횟수 | `returned` 이벤트 중, 그날 포함 3일 안(`local_date` +0~+2)에 `activity_completed`가 있는 건수 |
| 자율 일과 수립 일수 | `plan_created`가 있는 서로 다른 `local_date` 수 |
| 4주 지속 이용률 | 첫 이벤트 날부터 22~28일째에 기록(완료·쉬기)이 있는 참여 코드 비율 |

## 7. 화면별 완료 조건

### 긴급 연결 (C)
- [ ] 모든 화면 상단에 긴급 버튼이 있음. 버튼 → 연결 시트 → 전화, 총 두 번 누르면 전화 앱이 열림
- [ ] 109, 1577-0199, 연계 기관 연락처가 보이고 각각 바로 전화를 걺
- [ ] 네트워크가 없어도 동작함 (번호는 앱에 내장)
- [ ] `emergency_opened`, `emergency_called` 기록

### 처음 시작 (C)
- [ ] 참여 코드 입력 → 서비스 안내("진단·치료가 아님", 긴급 연결 위치) → 알림 시간 선택 → 정원 홈
- [ ] 이름·연락처를 묻는 입력란이 없음
- [ ] 익명 로그인과 `profiles` 생성

### 오늘의 미션 (B)
- [ ] 하루 1개 미션 제안, 다른 미션으로 바꾸기 가능
- [ ] 큰 → 중간 → 작은으로 낮출 수 있고, 다시 올릴 수도 있음
- [ ] 완료 또는 오늘은 쉬기. 쉬기 후에도 정원과 기록은 그대로이고 경고·불이익 문구 없음
- [ ] 밀린 미션이 쌓이지 않음 (어제 미션은 오늘 보이지 않음)

### 계획 정하기 — 2·3단계 (B)
- [ ] 2단계: 고른 미션에 시간·장소를 직접 입력
- [ ] 3단계: 활동과 성공 기준을 직접 작성 (미션 목록 없이)
- [ ] 설정과 미션 화면에서 단계를 자유롭게 오감

### 정원 홈과 완료 (A)
- [ ] 가로형 정원에 완료 1건당 꽃 1개, 쌓인 순서대로 배치
- [ ] 시드는 연출 없음. 며칠 빠져도 정원은 그대로
- [ ] 완료 직후 꽃이 피는 애니메이션, 한 줄 회고 입력(선택)

### 복귀 메시지 (A + C)
- [ ] 복귀 조건을 만족하면 정원 홈에서 "다시 왔네" 메시지 1회
- [ ] 메시지에 공백 일수를 보여 주지 않음 ("3일 만이네" 같은 표현 금지)
- [ ] `returned` 기록

### 기록 (A)
- [ ] 꽃을 누르면 그날 활동, 난이도, 메모가 보임

### 알림과 설정 (B)
- [ ] 사용자가 정한 시간에 하루 1회 로컬 알림, 끄기 가능
- [ ] 알림 문구에 압박·판단 표현 없음
- [ ] 설정: 알림 시간, 단계 변경, 연계 기관 연락처

## 8. 문구 원칙

- "해야 한다", "왜 안 했어요", "실패", "놓쳤어요" 같은 압박·판단 표현 금지
- 사용자의 상태를 해석하는 문장 금지 ("우울해 보여요" 등)
- 가장 작은 단계 미션은 1분 안에 끝낼 수 있을 것
- 모든 미션·안내 문구는 그린테라피 검수 후 반영
