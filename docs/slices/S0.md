# S0 프로젝트 뼈대·스키마·이벤트 기록

- 담당: C (A·B 리뷰)
- 브랜치: `s0-project-base`
- 목표: 앱이 켜지고, 익명 로그인 후 `app_opened` 이벤트 1건이 DB에 쌓인다. 이후 모든 슬라이스가 이 위에서 작업한다.

## 만들 것

### 1. Expo 프로젝트

- `create-expo-app` 최신 안정 SDK, TypeScript, expo-router 템플릿. 패키지 매니저는 npm, Node.js 22.
- 레포 루트에 생성한다. 이미 있는 `app/`, `src/`, `assets/`, `docs/`, `.github/`, `supabase/`, `.gitignore`, `.env.example`, `README.md`는 유지한다. 템플릿의 예제 화면·컴포넌트는 지운다.
- `package.json` 스크립트:
    - `typecheck`: `tsc --noEmit`
    - `lint`: Expo ESLint 설정 + `@typescript-eslint/no-explicit-any`를 error로
    - `test`: S0에서는 만들지 않아도 된다
- `tsconfig.json`: `strict: true`, `@/*` → `src/*`
- `package-lock.json` 커밋

### 2. 공통 라이브러리 (`src/lib/`)

| 파일 | 내용 |
|---|---|
| `supabase.ts` | `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY`로 클라이언트 생성. 세션은 AsyncStorage에 저장. 값이 없으면 개발 중에 이유를 알 수 있는 오류를 던진다 |
| `auth.ts` | `ensureSession()`: 세션이 없으면 익명 로그인, 있으면 그대로 사용. 사용자 id 반환 |
| `date.ts` | `toLocalDate(date?: Date): string` (Asia/Seoul `YYYY-MM-DD`, `Intl` 사용), `daysBetween(fromLocalDate, toLocalDate): number` |
| `events.ts` | 아래 "이벤트 기록" 참고 |
| `database.types.ts` | Supabase CLI로 생성 (아래 4번) |

### 3. 이벤트 기록 (`src/lib/events.ts`)

- PRD 4장의 12개 이벤트를 `EventName` union과 이벤트별 `props` 타입 맵으로 정의한다. 이름·필드는 PRD와 글자까지 같게.
- `logEvent(name, props)`: `user_id`, `name`, `props`, `occurred_at`(UTC 시각), `local_date`(KST)를 `events`에 insert.
- 기록에 실패해도 화면이 멈추거나 오류 화면이 뜨지 않는다. 개발 모드에서만 `console.warn`으로 이벤트 이름과 오류 메시지를 남긴다. `props` 전체를 출력하지 않는다.
- 다른 파일에서 `events` 테이블에 직접 insert하지 않는다.

### 4. Supabase 마이그레이션

`supabase/migrations/<타임스탬프>_create_base_schema.sql` 하나에 PRD 5장의 5개 테이블을 만든다.

| 테이블 | 컬럼과 제약 |
|---|---|
| `profiles` | `id uuid` PK = `auth.users.id`, `participant_code text`, `partner_code text`, `stage smallint default 1 check (1~3)`, `notify_time time`, `notify_enabled boolean default true`, `created_at timestamptz default now()` |
| `missions` | `id uuid` PK, `category text check (move, outing, tidy, connect, record, plant)`, `text_large`, `text_medium`, `text_small` (모두 not null), `reviewed boolean default false`, `created_at` |
| `activities` | `id uuid` PK, `user_id uuid` → `auth.users`, `mission_id uuid null` → `missions`, `custom_text text null`, `level text null check (large, medium, small)`, `stage smallint`, `status text check (completed, rested)`, `local_date date not null`, `memo text null`, `created_at` |
| `plans` | `id uuid` PK, `user_id uuid`, `stage smallint check (2, 3)`, `local_date date not null`, `time_text`, `place_text`, `activity_text`, `success_text` (모두 null 허용), `created_at` |
| `events` | `id bigint generated always as identity` PK, `user_id uuid not null`, `name text not null`, `props jsonb not null default '{}'`, `occurred_at timestamptz not null default now()`, `local_date date not null` |

- 인덱스: `activities (user_id, local_date)`, `events (user_id, local_date)`, `events (name, local_date)`
- RLS를 모든 테이블에서 켠다. 정책:
    - `profiles`, `activities`, `plans`: 본인 행(`auth.uid()`) select·insert·update. delete 정책은 만들지 않는다.
    - `missions`: 로그인 사용자는 `reviewed = true`인 행만 select. 쓰기 정책 없음.
    - `events`: 본인 `user_id`로 insert만. select·update·delete 정책 없음.
- `events.name`에 12개 이름 check 제약을 건다. 새 이벤트가 생기면 새 마이그레이션으로 바꾼다.
- 로컬 Supabase(Docker)를 띄울 수 있으면 `supabase gen types typescript --local > src/lib/database.types.ts`로 타입을 만든다. 못 띄우면 마이그레이션과 같은 모양으로 직접 쓰고 PR에 "직접 작성, 생성 필요"라고 적는다.

### 5. 미션 시드 (`supabase/seed.sql`)

아래 10개를 그대로 넣는다. 개발용이라 `reviewed = true`로 넣고, 파일 맨 위에 "개발용 시드. 그린테라피 검수 전. 시범 운영 전 교체" 주석을 단다. 문구를 고치지 않는다.

| # | category | 큰 | 중간 | 작은 |
|---|---|---|---|---|
| 1 | outing | 동네 카페까지 걸어서 다녀오기 | 집 앞까지만 나가 보기 | 창문 열고 바깥 공기 마시기 |
| 2 | tidy | 책상 전체 정리하기 | 책상 위 물건 5개 제자리에 두기 | 컵 하나 설거지하기 |
| 3 | move | 동네 10분 걷기 | 집 안에서 5분 스트레칭하기 | 자리에서 일어나 기지개 한 번 켜기 |
| 4 | tidy | 샤워하기 | 세수하고 양치하기 | 손 씻기 |
| 5 | connect | 친구나 가족에게 안부 전화하기 | 아는 사람에게 메시지 한 통 보내기 | 받은 메시지에 이모티콘 하나로 답하기 |
| 6 | record | 오늘 한 일 세 줄 적기 | 오늘 한 일 한 줄 적기 | 지금 떠오르는 단어 하나 적기 |
| 7 | plant | 공원이나 화단의 식물 구경하기 | 집 근처 나무 한 그루 찾아보기 | 창밖으로 보이는 초록색 하나 찾기 |
| 8 | tidy | 빨래 돌리고 널기 | 빨랫감 한곳에 모으기 | 옷 한 벌 개기 |
| 9 | outing | 마트에 장 보러 다녀오기 | 편의점에서 먹을 것 하나 사 오기 | 물 한 컵 따라 마시기 |
| 10 | move | 밖에서 15분 햇볕 쬐기 | 창가에서 5분 햇볕 쬐기 | 커튼 열기 |

### 6. 화면

- `app/_layout.tsx`: 앱 시작 시 `ensureSession()`, 앱이 포그라운드로 올 때마다 `logEvent('app_opened', {})`.
- `app/index.tsx`: "정원 홈 (준비 중)" 플레이스홀더 한 줄. 긴급 버튼은 S1에서 만든다.
- 문구는 `src/features/garden/copy.ts`에 둔다.

- Supabase 원격 프로젝트 생성, 대시보드 설정 변경
